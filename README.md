# EMusa Technologies — Microsoft 365 & IAM Administration Lab

A documented reference of Microsoft 365 Administration and Identity & Access Management
(IAM) procedures — covering the day-to-day and strategic work involved in managing an
organization's M365 tenant, from initial setup through ongoing access governance.

## About this playbook

This is built and maintained on a live Microsoft 365 tenant, documenting the actual
configuration steps, decisions, and outcomes for tasks a Microsoft 365 Administrator or
IAM System Administrator handles: identity security, device compliance, mail flow
governance, and access control for organizations of any size.

Each task folder includes the business scenario it addresses, what was configured, the
reasoning behind the approach, and proof of the working result (scripts, policy exports,
or screenshots).

## Skills demonstrated

**Microsoft 365 Administration:** Exchange Online, Microsoft Entra ID, Microsoft Teams,
SharePoint Online, OneDrive, Intune endpoint management, Microsoft Defender, Microsoft
Purview, PowerShell, Microsoft Graph API

**Identity & Access Management:** Conditional Access policies, MFA enforcement, RBAC and
admin roles, Enterprise Applications/SSO, Identity Governance, Privileged Identity
Management (PIM), Hybrid Identity, monitoring and auditing
