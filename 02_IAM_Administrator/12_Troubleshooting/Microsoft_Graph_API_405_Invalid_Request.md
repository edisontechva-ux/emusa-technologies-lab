# Microsoft Graph API 403 Permission Denied

## Issue

While creating users using Microsoft Graph Explorer, the request returned a **403 Forbidden / Permission Denied** error.

## Cause

The request did not have the required Microsoft Graph API permissions or admin consent was not granted.

## Resolution

- Reviewed the required Microsoft Graph permissions.
- Granted the necessary API permissions and admin consent.
- Retested the request after updating permissions.
- Successfully completed the user creation process.
