# Configure External Collaboration Settings

## Overview

External collaboration settings control how guest users interact with Microsoft Entra ID. These settings determine guest access permissions, invitation capabilities, and collaboration restrictions for external users.

## Location

**Microsoft Entra admin center → External Identities → External collaboration settings**

## Steps

1. Opened the **Microsoft Entra admin center**.
2. Navigated to **External Identities → External collaboration settings**.
3. Reviewed the guest user access restrictions.
4. Confirmed that guest users have limited access to directory object properties and memberships.
5. Reviewed the guest invitation settings.
6. Confirmed that users in the organization can invite guest users.
7. Reviewed the guest self-service sign-up configuration.
8. Reviewed the external user leave settings.
9. Reviewed the collaboration restrictions.
10. Saved the configuration where required.
11. Confirmed that the settings were successfully applied.

## Result

External collaboration settings were successfully reviewed and configured. The organization can control how guest users are invited and how they access Microsoft Entra resources.

## Administrative Notes

External collaboration settings help control guest access and B2B collaboration within Microsoft Entra ID.

Guest invitation permissions should be reviewed regularly to ensure only authorized users can invite external guests.

External collaboration settings should align with organizational security, compliance, and governance requirements.

Unused guest accounts should be reviewed and removed periodically.
