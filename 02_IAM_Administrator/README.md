# IAM Administrator

Identity and access management for a Microsoft 365 / Entra ID environment — covering
authentication, authorization, governance, and monitoring practices that keep an
organization's identities secure and access appropriately controlled.

Each topic area below documents specific administrative tasks: the business scenario
behind the task, the configuration steps taken, the reasoning behind the approach, and
proof of the working result.

## Topic Areas

| # | Topic Area | Covers |
|---|---|---|
| 01 | [Microsoft Entra ID](./01_Microsoft_Entra_ID) | User/group lifecycle, dynamic groups, group-based licensing, administrative units, devices |
| 02 | [Authentication and MFA](./02_Authentication_and_MFA) | Authentication methods, Microsoft Authenticator, SSPR, authentication strengths |
| 03 | [Conditional Access](./03_Conditional_Access) | MFA enforcement, legacy auth blocking, location/device-based policies, break-glass accounts |
| 04 | [RBAC and Admin Roles](./04_RBAC_and_Admin_Roles) | Built-in roles, least privilege, custom roles, privileged role assignments |
| 05 | [Enterprise Applications](./05_Enterprise_Applications) | SSO (SAML/OAuth/OIDC), SCIM provisioning, app assignment, application proxy |
| 06 | [Identity Governance](./06_Identity_Governance) | Access reviews, entitlement management, access packages, lifecycle workflows |
| 07 | [Privileged Identity Management](./07_Privileged_Identity_Management) | PIM setup, eligible vs active assignments, approval workflows, audit history |
| 08 | [Hybrid Identity](./08_Hybrid_Identity) | Entra Connect, password hash sync, pass-through auth, hybrid join, sync troubleshooting |
| 09 | [PowerShell](./09_PowerShell) | Connecting to Entra ID, scripted user/group/role management, bulk operations |
| 10 | [Microsoft Graph](./10_Microsoft_Graph) | API-based identity administration — users, groups, roles, applications, Conditional Access |
| 11 | [Monitoring and Auditing](./11_Monitoring_and_Auditing) | Sign-in/audit logs, risky users and sign-ins, Identity Secure Score, workbooks |
| 12 | [Troubleshooting](./12_Troubleshooting) | Common sign-in, MFA, Conditional Access, and sync issues and how they were resolved |

Tasks within each topic area are documented and expanded on an ongoing basis.
