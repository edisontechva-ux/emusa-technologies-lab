# Manage User Photos

## Overview

User profile photos help identify users across Microsoft 365 services and provide a consistent visual identity in applications such as Microsoft Teams, Outlook, SharePoint Online, and the Microsoft 365 admin center. Administrators can upload, replace, or remove user photos from the user's account settings.

## Location

**Microsoft 365 admin center → Users → Active users → Select user → Account → Manage profile photo**

## Steps

1. Opened the **Microsoft 365 admin center**.
2. Navigated to **Users → Active users**.
3. Selected the target user account.
4. Opened the user's account settings.
5. Selected the option to manage the user's profile photo.
6. Uploaded the appropriate profile image.
7. Reviewed the selected image before applying the change.
8. Clicked **Save changes** to update the user's profile photo.
9. Confirmed that the updated photo appeared in the user's account profile.

## Result

The selected user's profile photo was successfully updated in Microsoft 365. The new image appeared in the user's account profile and will synchronize across supported Microsoft 365 services.
