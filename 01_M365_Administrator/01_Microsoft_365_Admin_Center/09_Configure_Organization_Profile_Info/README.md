# Configure Organization Profile

## Overview

The Organization Profile contains tenant-wide information that identifies the organization within Microsoft 365. Administrators can manage details such as the organization name, address, contact information, preferred language, and privacy profile to ensure accurate tenant information and a consistent organizational identity across Microsoft 365 services.

## Location

**Microsoft 365 admin center → Settings → Org settings → Organization profile**

## Steps

1. Opened the **Microsoft 365 admin center**.
2. Navigated to **Settings → Org settings**.
3. Selected **Organization profile**.
4. Reviewed the organization name displayed in the tenant.
5. Reviewed the organization's primary address information.
6. Reviewed the organization's contact details.
7. Reviewed the organization's data location information.
8. Reviewed custom themes and organizational branding settings, if configured.
9. Reviewed privacy profile settings.
10. Reviewed release preference settings linked to organizational administration.
11. Clicked **Save** after confirming the organization profile information.
12. Verified that the organization profile settings were successfully reflected within the Microsoft 365 tenant.

## Result

The organization profile was successfully reviewed and configured within Microsoft 365. Tenant information was updated and accurately reflects the organization's identity, contact details, and administrative settings.

## Administrative Notes

The Organization Profile provides tenant-wide information used across Microsoft 365 services. Maintaining accurate organization details helps ensure consistency in administrative records, user-facing information, support requests, and service communications. Changes made within the Organization Profile should align with official company information and corporate branding standards.
