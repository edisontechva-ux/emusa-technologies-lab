# Generate Tenant Usage Reports

## Overview

Tenant Usage Reports provide administrators with insights into how Microsoft 365 services are being used across the organization. These reports help monitor adoption, user activity, storage consumption, and service utilization, supporting operational planning and license management decisions.

## Location

**Microsoft 365 admin center → Reports → Usage**

## Steps

1. Opened the **Microsoft 365 admin center**.
2. Navigated to **Reports → Usage**.
3. Reviewed the available Microsoft 365 usage reports.
4. Selected a usage report for a Microsoft 365 service.
5. Reviewed service adoption and activity metrics.
6. Reviewed reporting periods and usage trends.
7. Applied filters as required to refine report data.
8. Exported the report for further analysis.

## Result

The Microsoft 365 tenant usage reports were successfully reviewed and exported. Service adoption, user activity, and usage trends were analyzed to gain insights into Microsoft 365 utilization within the organization.
