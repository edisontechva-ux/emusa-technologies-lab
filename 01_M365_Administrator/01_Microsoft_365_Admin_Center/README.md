# Manage Service Requests

## Overview

Service requests allow Microsoft 365 administrators to contact Microsoft Support for technical, billing, subscription, and service-related issues that cannot be resolved through standard troubleshooting. Administrators can create support requests, provide diagnostic information, select a contact method, and monitor existing cases from the Microsoft 365 admin center.

## Location

**Microsoft 365 admin center → Support → Help & support**

## Steps

1. Opened the **Microsoft 365 admin center**.
2. Selected **Help & support**.
3. Entered a clear description of the issue in the Support Assistant.
4. Reviewed the recommended troubleshooting guidance and related support articles.
5. Confirmed that the suggested solutions did not resolve the issue.
6. Selected **Contact Support**.
7. Reviewed and confirmed the support contact information.
8. Selected the preferred contact method.
9. Provided the relevant issue details and diagnostic information.
10. Submitted the service request to Microsoft Support.
11. Opened the service request list to review the case status and support updates.

## Result

The Microsoft 365 support process was successfully reviewed, including issue submission, contact options, and service request tracking.

## Administrative Notes

A Microsoft 365 business administrator must have an eligible subscription and appropriate administrative access to contact Microsoft Support. If all subscriptions were purchased through a Microsoft partner, the organization may need to contact that partner for support instead.

Administrators should create a separate service request for each issue and include the affected service, user impact, troubleshooting already performed, relevant timestamps, screenshots, and error messages.
