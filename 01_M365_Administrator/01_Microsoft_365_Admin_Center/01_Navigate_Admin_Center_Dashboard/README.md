The Microsoft 365 Admin Center provides centralized access to Microsoft 365 tenant management features. The navigation menu contains the primary administrative areas used for managing users, devices, applications, services, subscriptions, and organizational settings.

---

# Navigation Menu

## Home

The Home page provides an administrator dashboard with quick access to common tasks, recommendations, service health information, and tenant insights.

Common activities:

- Review tenant overview
- Access frequently used admin tasks
- View Microsoft recommendations
- Monitor important notifications

---

## Copilot

The Copilot section provides management capabilities for Microsoft Copilot services within the organization.

Administrative tasks include:

- Manage Copilot settings
- Review Copilot configuration
- Monitor Copilot-related services
- Access Copilot administration features

---

## Agents

The Agents section provides administration features for Microsoft 365 agents and AI-powered organizational assistants.

Administrative tasks include:

- Manage available agents
- Review agent configurations
- Control agent availability
- Configure organizational AI experiences

---

## Users

The Users section is used for Microsoft 365 identity and account lifecycle management.

Administrative tasks include:

- Create and manage user accounts
- Reset passwords
- Assign or remove licenses
- Configure user properties
- Manage administrator roles
- Disable or remove accounts

Related documentation:

- User Management Documentation
- Identity and Access Management Documentation

---

## Devices

The Devices section provides management capabilities for organizational devices.

Administrative tasks include:

- View registered devices
- Manage device settings
- Review device compliance information
- Configure device management policies
- Support Microsoft Intune administration

Related documentation:

- Device Management Documentation
- Endpoint Management Documentation

---

## Teams & Groups

The Teams & Groups section manages collaboration resources across Microsoft 365.

Administrative tasks include:

### Microsoft Teams

- Manage Teams settings
- Configure Teams policies
- Review Teams configuration

### Groups

- Create and manage Microsoft 365 Groups
- Manage group ownership
- Configure group settings
- Manage distribution groups and security groups

Related documentation:

- Microsoft Teams Administration
- Group Management Documentation

---

## Marketplace

The Marketplace provides access to Microsoft and third-party applications and services.

Administrative tasks include:

- Discover available applications
- Review service offerings
- Purchase additional services
- Manage app-related subscriptions

---

## Billing

The Billing section manages Microsoft 365 subscriptions, licenses, and payment information.

Administrative tasks include:

- Review active subscriptions
- Purchase licenses
- Manage license assignments
- Monitor subscription usage
- Review invoices and billing information

Related documentation:

- License Management Documentation

---

## Setup

The Setup section provides guided configuration recommendations for Microsoft 365 services.

Administrative tasks include:

- Configure tenant settings
- Complete Microsoft 365 setup tasks
- Review recommended configurations
- Enable services
- Improve security posture

---

## Customize Navigation

The Customize Navigation option allows administrators to personalize the Admin Center menu.

Administrative tasks include:

- Pin frequently used services
- Remove unnecessary menu items
- Improve administrator workflow efficiency

---

## Show All

The Show All option expands the navigation menu and displays additional Microsoft 365 administration areas.

Additional administrative sections may include:

- Exchange Administration
- SharePoint Administration
- Security
- Compliance
- Reports
- Health
- Settings
- Migration
- Azure Active Directory / Microsoft Entra administration links

# Administrative Notes

The Microsoft 365 Admin Center navigation menu is the primary interface used for daily tenant administration.

Common operational activities performed through the Admin Center include:

- User provisioning and offboarding
- License management
- Device administration
- Collaboration management
- Service configuration
- Tenant monitoring
- Troubleshooting and reporting
