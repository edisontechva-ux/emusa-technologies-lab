# Monitor Service Health Dashboard

## Overview

The Service Health Dashboard provides administrators with visibility into the operational status of Microsoft 365 services. It displays active service incidents, advisories, maintenance events, and historical health information to help administrators monitor service availability and assess the impact of issues affecting users.

## Location

**Microsoft 365 admin center → Health → Service health**

## Steps

1. Opened the **Microsoft 365 admin center**.
2. Navigated to **Health → Service health**.
3. Reviewed the overall health status of Microsoft 365 services.
4. Reviewed any active incidents, advisories, or maintenance events.
5. Selected a service health event to view additional details.
6. Reviewed the event summary, impact, status updates, and recommended actions.
7. Reviewed service health history for previously resolved events.

## Result

The Microsoft 365 Service Health Dashboard was successfully reviewed. Current service status, ongoing advisories, maintenance notifications, and historical incidents were validated to ensure awareness of any issues affecting Microsoft 365 services.

## Administrative Notes

The Service Health Dashboard is one of the primary tools used by Microsoft 365 administrators to identify service disruptions and determine whether reported user issues are caused by Microsoft service incidents. Administrators should review service health regularly before troubleshooting large-scale service issues.
