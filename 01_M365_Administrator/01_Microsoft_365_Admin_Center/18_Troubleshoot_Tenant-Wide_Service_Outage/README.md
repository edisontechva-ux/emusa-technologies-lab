# Troubleshoot Tenant-Wide Service Outages

## Overview

Tenant-wide service outage troubleshooting helps administrators determine whether a widespread issue originates from Microsoft 365, the organization's environment, or a third-party dependency. The Service Health Dashboard provides incident status, affected services, user impact, Microsoft updates, and recommended actions. 【1-c27b34】【2-bebfee】

## Location

**Microsoft 365 admin center → Health → Service health**

## Steps

1. Opened the **Microsoft 365 admin center**.
2. Navigated to **Health → Service health**.
3. Reviewed **Issues for your organization to act on**.
4. Reviewed active incidents and advisories being investigated by Microsoft.
5. Selected the affected Microsoft 365 service.
6. Opened the related service health event.
7. Reviewed the incident ID, current status, user impact, and affected features.
8. Reviewed the latest Microsoft engineering update and recommended actions.
9. Compared the service health information with the issues reported by users.
10. Reviewed **Issue history** for recently resolved incidents and advisories.
11. Confirmed whether the reported issue was caused by a Microsoft service incident or the tenant environment.
12. Used **Report an issue** when the problem was not listed in Service Health.

## Result

The tenant-wide service issue was successfully investigated using the Microsoft 365 Service Health Dashboard. The affected service, incident status, user impact, and available Microsoft updates were reviewed to determine the appropriate response.

## Administrative Notes

Administrators should review Service Health before performing extensive troubleshooting when multiple users report the same issue. Active incidents and advisories provide tenant-specific information about Microsoft-managed service disruptions.

If the issue is not listed, administrators can use **Report an issue** to notify Microsoft. Reported issues and their status can be monitored from the **Reported issues** tab. 【1-c27b34】【3-70d623】
