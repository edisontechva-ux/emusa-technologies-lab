# Enroll Android Device Using a Personally Owned Device with Work Profile

## Overview

Personally owned devices with a work profile allow users to enroll Android devices into Microsoft Intune while keeping personal data separate from organizational data. Microsoft Intune manages only the work profile, helping protect company resources without affecting personal applications and content.

## Location

**Android Device → Google Play Store → Intune Company Portal**

**Microsoft Authenticator Application**

**Microsoft Intune Admin Center → Devices → All Devices**

## Steps

1. Opened **Google Play Store** on the Android device.
2. Installed the **Microsoft Intune Company Portal** application.
3. Opened **Company Portal**.
4. Signed in using the test user account.
5. Completed the **Multi-Factor Authentication (MFA)** registration process.
6. Installed **Microsoft Authenticator** when prompted.
7. Registered the device with Microsoft Authenticator.
8. Verified successful MFA enrollment.
9. Returned to **Company Portal**.
10. Selected **Begin** to start device enrollment.
11. Reviewed the organization's device management requirements.
12. Selected **Continue** to proceed with enrollment.
13. Created a **Work Profile** when prompted.
14. Allowed Android to configure the work profile.
15. Granted the required application permissions.
16. Waited for the device registration process to complete.
17. Verified that the work profile was successfully created.
18. Confirmed that work applications were available on the device.
19. Signed in to the **Microsoft Intune Admin Center** using an administrator account.
20. Navigated to **Devices**.
21. Verified that the Android device appeared in the device inventory.
22. Reviewed the device status and management information.
23. Confirmed successful Android device enrollment.

## Result

The Android device was successfully enrolled in Microsoft Intune using a work profile. Multi-Factor Authentication was configured successfully, and organizational resources were accessible through the managed work profile while personal data remained separate from company-managed data.

## Administrative Notes

Multi-Factor Authentication provides an additional layer of security during the enrollment process and helps protect organizational resources.

Personally owned devices with a work profile provide secure access to organizational resources while preserving user privacy.

Microsoft Intune manages only the work profile and does not manage personal applications or personal data stored outside the work profile.

Administrators should verify successful enrollment and policy assignment to ensure secure access to organizational resources.
