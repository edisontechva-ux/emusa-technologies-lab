# Microsoft 365 Administrator

Day-to-day and strategic administration of a Microsoft 365 tenant — covering the full
range of tools and services an M365 Administrator manages to keep an organization's
collaboration, communication, security, and compliance systems running reliably.

Each topic area below documents specific administrative tasks: the business scenario
behind the task, the configuration steps taken, the reasoning behind the approach, and
proof of the working result.
