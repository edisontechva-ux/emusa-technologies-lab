# Microsoft 365 Administrator

Day-to-day and strategic administration of a Microsoft 365 tenant — covering the full
range of tools and services an M365 Administrator manages to keep an organization's
collaboration, communication, security, and compliance systems running reliably.

Each topic area below documents specific administrative tasks: the business scenario
behind the task, the configuration steps taken, the reasoning behind the approach, and
proof of the working result.

## Topic Areas

| # | Topic Area | Covers |
|---|---|---|
| 01 | [Microsoft 365 Admin Center](./01_Microsoft_365_Admin_Center) | User lifecycle, licensing, bulk operations, admin roles, domains, org settings |
| 02 | [Exchange Online](./02_Exchange_Online) | Mailboxes, distribution lists, mail flow rules, retention, litigation hold |
| 03 | [Microsoft Teams](./03_Microsoft_Teams) | Team/channel management, guest access, policies, call queues, reporting |
| 04 | [SharePoint Online](./04_SharePoint_Online) | Sites, permissions, external sharing, storage, hub sites, administration |
| 05 | [OneDrive](./05_OneDrive) | Provisioning, storage quotas, sharing, sync, file restore, ownership transfer |
| 06 | [Microsoft Intune](./06_Microsoft_Intune) | Device enrollment, compliance policies, configuration profiles, app deployment |
| 07 | [Microsoft Defender](./07_Microsoft_Defender) | Safe Links/Attachments, anti-phishing, anti-spam, incident response, Secure Score |
| 08 | [Microsoft Purview](./08_Microsoft_Purview) | Sensitivity labels, DLP, retention, eDiscovery, compliance management |
| 09 | [PowerShell](./09_PowerShell) | Module setup, connecting to M365 services, scripted user/license/group management |

Tasks within each topic area are documented and expanded on an ongoing basis.
