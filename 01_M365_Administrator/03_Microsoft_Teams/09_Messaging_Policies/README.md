# Configure Messaging Policies

## Overview

Messaging policies control chat and messaging features in Microsoft Teams, including message editing, deletion, chat availability, read receipts, and communication capabilities.

## Location

**Microsoft Teams admin center → Messaging policies**

## Steps

1. Opened the **Microsoft Teams admin center**.
2. Navigated to **Messaging policies**.
3. Reviewed the available messaging policies.
4. Selected **Add**.
5. Entered a policy name and description.
6. Configured message editing settings.
7. Configured message deletion settings.
8. Configured chat permissions.
9. Reviewed read receipt settings.
10. Reviewed user communication settings.
11. Selected **Save** to create the policy.
12. Confirmed that the policy appeared in the policy list.
13. Opened the policy and reviewed the configured settings.
14. Assigned the policy to a test user where applicable.
15. Verified that the policy was successfully applied.

## Result

The messaging policy was successfully created and configured. Chat and messaging features were controlled according to organizational requirements.

## Administrative Notes

Messaging policies help standardize communication features across Microsoft Teams.

Policies can be assigned to specific users or groups when different messaging experiences are required.

Messaging settings should be reviewed periodically to ensure they align with organizational governance and security requirements.
