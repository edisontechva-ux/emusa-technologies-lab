# Configure Guest Access

## Overview

Guest access allows external users to collaborate in Microsoft Teams using their own identities. Guests can participate in conversations, access shared files, join meetings, and collaborate within teams based on assigned permissions.

## Location

**Microsoft Teams admin center → Users → Guest access**

## Steps

1. Opened the **Microsoft Teams admin center**.
2. Navigated to **Users → Guest access**.
3. Reviewed the current guest access configuration.
4. Enabled guest access for Microsoft Teams.
5. Reviewed calling, meeting, and messaging permissions for guest users.
6. Configured the required guest access settings.
7. Selected **Save** to apply the changes.
8. Waited for the configuration to synchronize.
9. Verified that guest access remained enabled.
10. Invited a guest user to a Microsoft Team.
11. Confirmed that the guest user appeared in the team membership list.
12. Verified that the guest user could access the team according to the configured permissions.

## Result

Guest access was successfully configured in Microsoft Teams. External users can collaborate within teams according to the configured access and permission settings.

## Administrative Notes

Guest access should be configured according to organizational security and collaboration requirements.

Only approved external users should be granted guest access.

Guest permissions should be reviewed periodically to ensure appropriate access is maintained.

Organizations should monitor guest activity and remove unused guest accounts when they are no longer required.
