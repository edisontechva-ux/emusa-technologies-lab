# IAM Administrator Backlog

## Overview

This folder tracks Identity and Access Management labs that are planned but cannot currently be completed because of licensing, subscription, identity governance, hybrid infrastructure, application, or resource requirements.

Each task remains in the backlog until the necessary requirement becomes available. Once completed, the task documentation will be moved to the appropriate folder under `02_IAM_Administrator`.

## Pending Tasks

No IAM administration tasks are currently pending.

## Backlog Process

1. Identify the requirement preventing completion of the lab.
2. Record the current status and reason for postponement.
3. Obtain the required license, subscription, infrastructure, application, or technical resource.
4. Complete and validate the identity administration task.
5. Add screenshots, scripts, policy exports, or other evidence of completion.
6. Move the completed task to the appropriate IAM Administrator folder.
