# Configure Multi-Geo Capabilities

## Status

**Pending**

## Reason

The Microsoft 365 tenant is not currently licensed or enabled for Multi-Geo capabilities. The **Geo locations** option is not available in the SharePoint admin center.

## Resume When

- The Microsoft 365 Multi-Geo Capabilities add-on is available.
- Multi-Geo has been enabled for the tenant.
- Satellite geography locations can be configured.
- Test users are available for Preferred Data Location configuration.
